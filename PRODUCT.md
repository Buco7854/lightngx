# Lightngx

## Platform
Web, React 19, TypeScript, Tailwind CSS 4, Vite, embedded in a Go binary.

## Product purpose
A lightweight nginx management interface. Guarded configuration editing, site and stream management, live log viewing, and nginx test/reload/restart.

## Users and workflows
Repository-derived audience: server administrators and self-hosters. They inspect enabled sites, edit nginx files, validate and reload changes, investigate logs, and manage access.

## Constraints
Preserve existing routes, APIs, business logic, authentication, OIDC, passkeys, MFA, API keys, roles, tags, filtering, bulk actions, file operations and safety confirmations. Preserve English/French and light/dark/system preferences. No invented production metrics or demo data in the app.

## Design authority
The user explicitly delegated every visual decision and requested a complete redesign, implementation, browser verification and iteration. User research beyond the repository has not been performed.
